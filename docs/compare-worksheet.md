## 使用说明

1. 「长期价」以恢复后的价格为准，不要用首月优惠价做对比
2. 「运营商官方 App 可查」是正规卡的核心判据，填「是/否」
3. 合约期内注销的违约成本，问清客服后写进备注
4. 三列填满后，剔除任何一项「否」的候选再比价格
